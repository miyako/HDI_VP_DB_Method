# HDI_VP_DB_Method

A 4D v18 **HDI** (How Do I) binary database converted to a 4D project using 4D 21. The codebase was then updated and cleaned up with the help of **GitHub Copilot**.

## Origin

This project started as a binary `.4DB` example database originally distributed with 4D {version}. It was converted to the modern project architecture (`.4DProject`) using 4D 21's built-in binary-to-project conversion tool.

- **Blog post:** https://blog.4d.com/use-methods-and-database-fields-in-4d-view-pro/

- **Original download:** https://download.4d.com/Demos/4D_v17_R2/HDI_VP_DB_Method.zip
